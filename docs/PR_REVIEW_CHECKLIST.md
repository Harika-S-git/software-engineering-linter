# Authentic PR review checklist

- [ ] Assigned teammate raises a PR from their own account referencing its story issue.
- [ ] Quality gate shows green Flake8, Black and Pytest checks.
- [ ] Repository owner reviews and approves/comments through GitHub.
- [ ] Owner merges only after approval, updates issue status and links the merged commit.
- [ ] Attach authentic PR/Actions screenshot showing author, reviewer and status.

A PR opened by the repository owner cannot be represented as a teammate-authored PR.
